SETUP

Two builders, identical physics cuts

BASELINE

SnippetHit3DBuilderDUNE

Takes triplet candidates first-come in wire order. A hit pair can sit in only one triplet.

FAST

SnippetHit3DBuilderDUNEFast

Scores every candidate triplet and keeps up to 16 per pair. Cuts are the same as the baseline.

Fast builds more 3D points but without an obvious gain in the truth metrics we cared about, so we asked where true points are lost.

Not tuned: MaxHitChiSquare and MaxMythicalChiSquare, because SPINE/Supera deghosting uses them.

The two tools share the same hit-level cuts and differ in how candidates are chosen. The standing constraint is that we do not tune the chi-square cuts, since SPINE and Supera deghosting depend on them. Test sample: 8 FD HD events, run 330003.
