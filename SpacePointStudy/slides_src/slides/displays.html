See the truth next to the points

  • Layers switch on and off: SimEnergyDeposits, SimChannel positions, true 3-hit and 2-hit points, other points.
  • Pick the label (ball or single deposit), f, R and the position check in the page.

Self-contained HTML pages made by sp_display.py, one per builder variant, 3 events each.

The displays are how we found the long-hit and inclined-track problems: a clear track in the deposits with only gray points on it. They are single HTML pages that load three.js from a CDN. The screenshot shows the baseline page for event 0 with the ball label selected.
